Questo progetto simula l’analisi di un file contenente dati relativi a diversi macchinari industriali.

Il programma legge e valida i dati, li elabora e mostra i risultati sia nel terminale sia in un file CSV di output, il cui nome può essere scelto dall’utente.

Per ogni macchina vengono calcolati:

* pezzi prodotti;
* numero di difetti;
* percentuale di scarti;
* tempo medio di ciclo;
* periodi di fermo macchina.

Il programma viene avviato tramite `main.py`, mentre la logica di validazione, analisi ed esportazione dei dati è contenuta in `analyzer.py`.

Un esempio di output è disponibile nel file `result.csv`.

Con questo progetto ho applicato le basi di Python per la lettura, validazione, trasformazione e analisi di dati strutturati, oltre alla gestione di file CSV e alla suddivisione del codice in moduli.
